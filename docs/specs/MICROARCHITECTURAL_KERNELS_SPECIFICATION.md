# Interaction Primitive Families (IMF): Grand Microarchitectural Specification & Hardware Catalog

> **Current Status**: Complete, Verified Microarchitectural Register across 229 Components (138 CUDA Kernels, 91 C++ Engines, 234 Native Shared Objects).
> **Hardware Targets**: NVIDIA Blackwell SM 12.0 (RTX 5060 Ti 16GB GDDR7 / GB200), AMD Ryzen 5 7600X, Linux Kernel-Bypass Direct-DMA, POSIX NUMA Node 0.

---

## Executive Architectural Summary

The IMF runtime bypasses standard OS memory paging and heavy frameworks in favor of bare-metal C++20 and CUDA kernels executing directly within GPU warp registers and cacheline-aligned POSIX shared memory. All operations are strictly co-designed with our formal Lean 4 mathematical foundations (Lie algebras, exceptional root lattices, and symplectic geometry).

## III. Microarchitectural Taxonomy by Operational Domain

### 1. Lie Algebra & Exceptional Polytope Routers
- **Components**: `fused_e8_root_lattice_routing.cu`, `fused_e6_albert_routing.cu`, `fused_e7_freudenthal_routing.cu`, `fused_f4_jordan_routing.cu`, `fused_g2_automorphism_routing.cu`, `fused_monster_moonshine_routing.cu`, `fused_niemeier_lattice_routing.cu`, `fused_leech_shell_routing.cu`, `fused_blackwell_leech_mope.cu`, `fused_blackwell_bit_mope_topk_routing.cu`.
- **Description**: Computes projection distances onto exceptional root lattices and the 24D Leech lattice $\Lambda_{24}$ using 196,560 minimal vectors for MoPE mixture-of-polytope routing.

### 2. Symplectic Integrators & Continuous SDE/ODE Solvers
- **Components**: `fused_blackwell_bit_yoshida6.cu`, `fused_blackwell_bit_neural_jump_ode.cu`, `fused_blackwell_bit_adjoint_neural_ode.cu`, `fused_blackwell_bit_ssm_ode_solver.cu`, `fused_geodesic_flow.cu`.
- **Description**: Preserves Poincaré symplectic invariants $\omega = \sum dq_i \wedge dp_i$ using 6th-order Yoshida time-reversible integrators and Poisson jump assimilation in registers.

### 3. In-Register Linear Algebra & Spectral Decompositions
- **Components**: `fused_blackwell_bit_shifted_qr.cu`, `fused_blackwell_bit_lanczos.cu`, `fused_blackwell_bit_clifford_fft.cu`, `fused_blackwell_bit_jacobi_svd.cu`, `fused_blackwell_bit_hessenberg.cu`, `fused_blackwell_bit_cholesky_inv.cu`, `fused_blackwell_bit_givens_qr.cu`, `fused_cayley_inverter.cu`.
- **Description**: Executes Francis shifted QR iterations, Lanczos Krylov projections, Clifford bivector rotor FFTs, and Jacobi SVD entirely inside warp registers with zero DRAM roundtrips.

### 4. Sub-Byte Quantization & Tensor Core MMA Engines
- **Components**: `fused_blackwell_bit_serial_mma.cu`, `fused_blackwell_fp4_gemv.cu`, `fused_blackwell_fp8_gemv.cu`, `fused_blackwell_plq_gemm.cu`, `fused_blackwell_mixed_ternary_fp4.cu`, `fused_blackwell_ternary_dot.cu`, `fused_blackwell_bit_syrk.cu`, `fused_leech24_gemv.cu`, `fused_plq_gemv.cu`.
- **Description**: Hardware-fused sub-bit (0.58–1.58 bpw) dequantization and matrix-vector multiply leveraging NVIDIA Blackwell FP4/FP8 tensor instructions.

### 5. Direct-DMA, NUMA Slab Pooling & Linux Kernel-Bypass Engines
- **Components**: `fused_dma_numa_pool.cpp`, `fused_dma_ring_broadcast.cpp`, `fused_dma_async_pager.cpp`, `fused_dma_work_stealing_queue.cpp`, `fused_dma_shm_barrier.cpp`, `fused_gpu_rdma_checkpoint_sync.cpp`, `fused_iouring_sqpoll_ring.cpp`, `fused_nvme_async_prefetch_pipeline.cpp`.
- **Description**: Hugepage 2MB memory pooling pinned to NUMA node 0 via POSIX `mbind` with `MPOL_BIND` and lock-free ring buffers for sub-microsecond multi-GPU synchronization.
