Berkovich Analytic Spectrum M(A)

3D visualization of Vladimir Berkovich's non-Archimedean analytic space as a piecewise-linear real tree with branching disc stratifications.

Space:A¹_Berk / M(K{T})
Topology:Compact & Hausdorff
Geometry:R-Tree Retraction
Type I:Classical Points (Leaves)
Type II:Rational Branch Discs
Type III:Irrational Radii Segments
Type IV:Dead-End Filter Points
Spectral Radius:ρ(f) = lim ||f^n||^{1/n}
Orbit Controls: Left Drag: Rotate | Right Drag: Pan | Scroll: Zoom
