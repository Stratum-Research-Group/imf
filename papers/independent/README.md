# Independent Papers

Paper types in this repository:

| Type | Location | Notes |
|---|---|---|
| **Normal** (corpus) | `papers/phase_*/paper_NNNN_*.md` | Numbered treatises in the 1,3xx corpus. Standard header: `# Paper {ID}: {TITLE}` + bold metadata. |
| **Independent** | `papers/independent/` | Stand-alone papers written on explicit request. Not numbered into the corpus, not part of the 100M-step reporting cadence. |
| **Thesis / Theses** | `theses/` (never `papers/`) | Multi-volume works. Chapters in `theses/volume_*/`, compiled books in `theses/compiled/`. |
